## Principais Arquivos

- **index.html**: Estrutura principal do site, com header fixo, hero, categorias, grid de produtos e footer.
- **css/reset.css**: Reset de estilos para garantir consistência entre navegadores.
- **css/variables.css**: Variáveis globais, como fontes.
- **css/base.css**: Estilos base e utilitários.
- **css/componentes/**: Estilos separados por componentes (header, hero, categorias, grid de produtos, footer).
- **images/**: Imagens de banners, produtos, ícones e logo.

## Funcionalidades

- Header fixo com navegação principal e ícones de conta, ajuda e carrinho.
- Seção hero com chamada para ação e imagem de destaque.
- Categorias de produtos com navegação rápida.
- Grid de produtos em destaque.
- Footer com newsletter, redes sociais e navegação adicional.

## Como rodar o projeto

1. Clone o repositório:
	```bash
	git clone https://github.com/Guga-Kojiro/ecommerce-syntaxwear.git
	```
2. Abra o arquivo `index.html` em seu navegador.

## Tecnologias utilizadas

- HTML5
- CSS3 (com organização modular)
- Google Fonts (Ubuntu)
